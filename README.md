# Al Shahriar Nayeem — Portfolio

Personal portfolio website for **Al Shahriar Nayeem**, a Full-Stack Developer and Computing graduate focused on product engineering and AI-powered applications.

Portfolio: https://www.alnayeem.com

## Built with

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS 4

## What it showcases

- Software engineering experience
- Selected web and mobile projects
- Full-stack and AI-focused development work
- Technical skills and professional background
- Links to GitHub and LinkedIn

## Running locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.

Production build:

```bash
npm run build
npm start
```

Type checking:

```bash
npm run typecheck
```

## Purpose

This repository contains the source code for my personal developer portfolio and is used to present selected projects and experience to potential employers and collaborators.
